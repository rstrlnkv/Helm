# Island Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline). Steps use `- [ ]`.

**Goal:** Notch island — invisible at rest, hover/drag reveals it, expands downward; first source is a file shelf (bookmark references, drag-in/out, persist). Spec: `docs/superpowers/specs/2026-07-25-island-design.md`.

**Architecture:** Module `island` (`Module_Island_Engine` + `Module_Island_UI`). Engine: pure `NotchMetrics`, `IslandStateMachine`, `ShelfStore` (+ port for bookmark IO). UI: descriptor owning `IslandWindowController` (static-frame transparent panel per ARCHITECTURE.md rules), SwiftUI content, settings page. Risk gate first: drag-detection over an invisible window.

**Tech Stack:** Swift 6, AppKit/SwiftUI, XCTest.

## Task 4: IslandStateMachine (TDD)

**Files:** `Sources/Modules/Island/Engine/Logic/IslandStateMachine.swift`, tests.

- [ ] **Failing tests** (core rules):
```swift
final class IslandStateMachineTests: XCTestCase {
    func testHoverExpandsAndGraceCollapses() {
        var m = IslandStateMachine()
        XCTAssertEqual(m.state, .hidden)
        m.apply(.hoverEntered);            XCTAssertEqual(m.state, .expanded)
        m.apply(.hoverExited);             XCTAssertEqual(m.state, .expanded)   // grace
        m.apply(.graceElapsed);            XCTAssertEqual(m.state, .hidden)
        m.apply(.hoverEntered); m.apply(.hoverExited); m.apply(.hoverEntered)
        m.apply(.graceElapsed);            XCTAssertEqual(m.state, .expanded)   // re-enter cancels grace
    }

    func testDragRevealsAndDropExpandsPinned() {
        var m = IslandStateMachine()
        m.apply(.dragEntered);             XCTAssertEqual(m.state, .expanded)
        m.apply(.dragExited); m.apply(.graceElapsed)
        XCTAssertEqual(m.state, .hidden)
        m.apply(.dragEntered); m.apply(.dropped)
        XCTAssertEqual(m.state, .expanded)                                       // stays for review
    }

    func testTransientEventPeeksAndTTLHides() {
        var m = IslandStateMachine()
        m.apply(.event(id: "battery", priority: 1)); XCTAssertEqual(m.state, .peek)
        m.apply(.eventExpired(id: "battery"));       XCTAssertEqual(m.state, .hidden)
    }

    func testExpandedBeatsPeek() {
        var m = IslandStateMachine()
        m.apply(.hoverEntered)
        m.apply(.event(id: "battery", priority: 1))
        XCTAssertEqual(m.state, .expanded)
        m.apply(.hoverExited); m.apply(.graceElapsed)
        XCTAssertEqual(m.state, .peek)      // event still alive → falls back to peek
    }

    func testDismissCollapsesEverything() {
        var m = IslandStateMachine()
        m.apply(.hoverEntered); m.apply(.dismiss)
        XCTAssertEqual(m.state, .hidden)
    }
}
```
- [ ] **Implement**: value type, `enum State { hidden, peek, expanded }`,
  `enum Input { hoverEntered, hoverExited, graceElapsed, dragEntered, dragExited, dropped, event(id:priority:), eventExpired(id:), dismiss }`.
  Track `hovering/dragging/pinned` flags + live events set; derive state:
  expanded if hovering‖dragging‖pinned, else peek if any live event, else hidden.
  `dropped` sets pinned; `dismiss` clears pinned+events flags.
- [ ] Tests pass. Commit: `feat(island): state machine (TDD)`.
