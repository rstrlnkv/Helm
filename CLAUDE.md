# Helm — how to work here

`README.md` says what Helm is. `ARCHITECTURE.md` describes how Helm is built; nothing here repeats it: order here, description there; a rule without a reason is litter, delete it. After an arrow, § X is a heading there; a backticked file's doc comment holds the reason.

## Commands

- `bash Scripts/test.sh` runs the suite, `--filter '<Name>|<Other>'` a family; read a run by the script's last line; "Test Suite 'All tests' passed" is the last bundle, "✔ Test run with 0 tests in 0 suites passed" the empty Swift Testing run; the runner fails a `--filter` alternative that ran none, naming it, a bare `swift test` partial filter exits 0 → `test.sh` header.
- `swift build --target <Name>` for one target, a release only as `swift build -c release --product HelmApp`; package with `bash Scripts/package-app.sh`, install only its signed `$TMPDIR` copy; `bash Scripts/package-dev.sh` to click through; version from `/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' Resources/HelmApp/Info.plist` → § Targets, § Release.
- After a token moves, `HELM_WRITE_DESIGN_TOKENS=1 bash Scripts/test.sh --filter PublishedTokensAreTheTrees` regenerates `Resources/DesignSystem/design-tokens.json`; never passes, record republished outside → § Design system.
- After a hand edit `plutil -lint Sources/HelmUI/Resources/*.lproj/Localizable.strings`; after touching a `.strings` file, before the suite, `bash Scripts/test.sh --filter 'PunctuationIsTerminologyTests|StringsCoverageTests|NoOrphanTranslationsTests'` → § Tests and measurement.
- "Who uses this" from an index, never `grep`: `swift build --build-tests`, then `periphery scan --skip-build --index-store-path "$PWD/.build/out" --format csv`; its report is no to-do list; keep `command grep -rn HELM_DEBUG Sources/` empty before every commit; before cleanup `du -sh "$TMPDIR"`, then what is not `helm-*`; `--scratch-path` only if another run is up, one per session → § Tests and measurement.
- Read `~/Library/Logs/Helm/helm.log`, its `[permissions]` line, not assumptions → § Diagnostics log.

## Before you touch the code

- Work goes through lead — Use lead: and the task; superpowers skills only to think, never subagent-driven-development or executing-plans; no spec or plan in tree; reach outside the tree by full path from a worktree → § What else to read.
- `ls Sources/HelmRuntime`, `ls Sources/HelmUI/DesignSystem`, `ls Tests/Support` before writing a helper → § Tests and measurement.
- Gate before widening reach: `RemovableScope.swift` applications, `UserFileScope.swift` user's files, `WatchScope.swift` unattended rules, `ScanRoot.swift` unwatched reads, `SSHFileScope.swift` *writes* → § The gates.
- Of every stored reading ask what happened before the act, and who re-asked → § The gates.
- Value crossing `DispatchQueue.main.async`: *reading* inside the block, *payload* captured before → § Module pattern.
- Of an event-stream value ask which event clears it, what if it never comes → § State and lifetime.
- Where is a value read from, how often, before sealing → `SettingGuard.swift`.
- What would *total* failure of a new check's subject print; put the defect back, watch it go red → § Tests and measurement.
- Who draws a thing, what identity a view keeps across a change, before fixing → § Design system.
- Build from a fresh `git clone` before release → § Release.

## What not to do, and what breaks if you do

- No other engine imported into module or host, no SwiftUI or shared UI target into an engine, AppKit only as system calls in that module's own ports file; module id from engine, not literal; no `default:` on command switch, payload declared once in engine → § Module pattern.
- Delete only what passed the gate *inside the engine*, widen no scope without a test naming the path; removals via `HelmTrash.swift`; every refused path in removed or failed list (`TrashFailure`), never neither; no folder size from `totalFileAllocatedSize`, clone family counts once, unreadable family id counts as its own file → § Removal.
- Re-read the pair before it moves, memoise only the survivor's reading; re-ask whether the app still runs after the quit loop; filter glob and bundle-id paths two ways against what is installed; quit port quits every copy → § Uninstaller, § Duplicates.
- Root gets content, not staged path; base64 gates root's AppleScript, escaped only in `AppleScript.swift`, backslash before quote; count decoded bytes before redirect; secret never a string nor in argv, env, file or log: in-out, zeroed on every exit, failed spawn and deadline too, silence echo yourself; no key generation at existing name; parsed hosts file is a reading, known-hosts lines byte-for-byte, edited only by dropping a whole line → § Hosts.
- No `/etc/sudoers.d` rule for what is reachable another way, no Autopilot script action; grant carries its revocation, argument-exact, one literal path, except `/opt/homebrew`'s ownership; no dialog on way out, rule too old to withdraw itself stays → § KeepAwake, § Autopilot.
- Bind per-app rules to code signature (`CodeIdentity.swift`), never bundle id, no recorded identity refuses; names via `Redact.swift` in logs, files naming somebody's files via `PrivateFile.swift`, not atomic write plus mode change → § VPN.
- Seal unattended-work settings, broken seal refuses safe, never refuse to *save*; seal nothing an initialiser reads, a SwiftUI state's initial value included, first use at getter's early return, cache key not verdict; only a missing key signals migration; write nothing back from refused read; never re-key a deployed keychain item, new setting new account; one lock over read-judge-record, another over save, both sides of the field in a synchronous property, never across a suspension → § Sealed settings.
- Judge descent by directory *name*, never by reading, at each; strip `/private` from both sides, compare protected prefixes in both spellings, test gates on existing paths; nil report is not empty one, write attempt first; probe file, not directory, common entry first → § The gates, § Background scans, § Permissions.
- Read apps via `RunningApps.swift`, `FrontmostApp.swift`, never off main, moving work off main changes every AppKit call it reaches; launch via `Sources/HelmLaunch`, catch what it raises; hop blocking calls via `OffTheCooperativePool.swift`; read stdout before waiting, null device if unread; split on newline byte, end at empty pipe; stderr unparsed; cap tools at once, excess queues, never an unbounded launch behind a control pressable repeatedly → § Running applications, § Running other programs.
- Read exit status and stdout of network query together, prune no book on one read; deadline read-only queries, halve a batch on retry not the timeout, stream long operations, keep last answer on timeout and log it → § VPN, § Homebrew.
- `autoreleasepool` inside bulk file-read loop, never around, none in resource-values loop, keep that negative measurement as a test (`WalkFootprintTests.swift`); judge call by its requests, not sampled peak; per-object cost from allocator's books, process cost from footprint, no peak blamed on neighbouring log line; no composed path stored nor breadth-first stack of node-and-path pairs, compose from the name through `ScanPath.swift` with its child helper; device id signed never unsigned; bound growing records → § Module pattern, § The memory trail.
- Stop every observer in deactivation, give object `deinit`, no bootstrap of live module; no retained C context, remove run loop source and invalidate it, cancel subscriber tasks outside `deinit`; read a tap's disablement → § State and lifetime.
- Bound every property-list value in engine by one shared ceiling; clamp via `Clamped.swift`, say per site what not-a-number means; when a fix adds a bound ask which direction tests exercise → § A number that came from a file.
- Port doc comments name reasons collapsing into empty read, no sentinel; a caller that must tell reasons apart gets a second entry point or an enum naming each, no unreadable system answer folded toward permissive without asking whether the guard below needs the difference; changing ports get reverse channel, fakes too; reload settings in activation; log refusal, not absence, and run any state-of-the-world line on an ordinary machine counting how often it is silent → § Module pattern, § Diagnostics log.
- Open phase with registry's phase call, bare begin only with `defer` on the next line and only where the phase is the whole async body, label on the shared path; bulk phase gets named interval and memory reading or stays off the trail, the trail never says the app is idle; follow tail by newest line identity, fill it from the parts the file line is spelled from, parse back only in `LogSeed.swift`, reuse a cached date format → § The activity registry, § The memory trail, § The log pane.
- Strings: English-key lookup in all eight folders, different English for a second meaning; call the same string the control calls, or a rename strands the sentence; no verb interpolated, each variant a full key with its own eight translations; quotes from `L10n.swift`; French in a pass of its own, unbreakable space by escape, `command grep -c` before and after; system spellings from macOS's *displayed* table; `table:` only for interpolated keys; formatters via UI target, never static → § Localization.
- Curves only from `HelmMotion.swift`, reduce-motion flag a computed property; reveal by clipped measured height, not insertion or fading, inside it a literal primary colour with an opacity, not secondary or tertiary; measure inside landing transaction, do not animate the first measurement; widths from sibling, a threshold against the widest string in every language, what window ever crosses it; cards, glass, badge, empty states from `HelmSurfaces.swift`, `HelmBadge.swift`, never a border on a card, no edge on glass, reach for a row in the card before the grouped-header outset; ladders and signal palette; name every control; contrast against what it draws on, check a control can be photographed; blend tint inside its appearance, sRGB on the way in, retire stored case never remove; menu swatch pre-coloured non-template, colour panel's target held from the view → § Design system.
- Refresh published sets before veto returns, built once from the same expressions the behaviour consults; say stopped guard on wire, it takes the one notice slot when both it and a pause are true, slot gated on "there is something to say", no button; per-rule facts per-rule, mark a module macOS blocks from the declared permission, not the switch → § KeepAwake, § Autopilot.
- Refuse payload equal to last; unmount hidden window's page, never pause its model; password gesture on *edge* not value, consumed before module's active guard, edge while idle spent not saved; completeness over every part of a value, one predicate, never a flag true mid-walk; hand-written initialiser for older payloads → § State and lifetime, § KeepAwake, § VPN.
- Measuring test asserts, subject happened first; structure, not sizes, in volume walks, re-run alone at least three times before trusting a result found while more than one suite run was up; commit before mutating, restore mutant from copy never `git checkout`, read the mutant back from file; a fake stands for one side of a boundary, carries port's states only, finishes its prompt, port named at every construction; busy-gate runners never exit, no cooperative yield as a wait; scratch via `ScratchDirectory.swift`, a restore outliving sweep as teardown block; harness on temp folder, clean Helm's Application Support after, nothing under `/Applications` removed that may predate session, prove what it launches can replace what it kills, Accessibility granted to top of launch chain; name a render's appearance, read twice; language assertions via `EachLanguage.swift`; motion by screen recording, never in a timeout nor from a hosting view's fitting size, shoot by window number; pixel probes: timestamp loop, anchor on what moves, crop, shipping duration, ship the control → § Tests and measurement.
- Keep checkout from under file provider, sign from staged path `package-app.sh` prints → § Release.

## Where things go

- New module: `Sources/Modules/<Name>` Engine and UI, `Tests/Modules/<Name>` EngineTests and UITests, descriptor in `ModuleRegistry.swift`; commit a file into each test directory before pushing → § Module pattern.
- Shared strings and controls in `Sources/HelmUI`, test plumbing in `Tests/Support`, no simpler than what it replaces, a local helper doing more keeps its body and calls the shared one, app-layer checks in `Tests/HelmAppTests`; `public` means another target uses it, demote by the compiler not by reading, expect several passes → § Targets.
- Hand-written list of module ids next to the thing it names, or it becomes a comment; scanning module conforms its engine and enters `ScanRunner.swift`, `ListsAgreeWithTheTreeTests.swift` fails on either half → § Background scans.
- Declare a name in any document rather than discuss it, only what tree has; removed name to known-absent list with its reason, macOS's to foreign list, anything else failing means the backticks were the mistake; command, not count; documents beside `Package.swift`, the check skips out loud when none, which a failures-only summary reads as green → `DocumentsNameTheTreeTests.swift`, § What else to read.

## Shipping — what a person does, not a role

- Compose no changelog text in `ChangelogData.swift`; check entry's control names against running app → § Release, § What shipped.
- Bump short version in `Resources/HelmApp/Info.plist` each release, never bundle version; patch resets on minor, both on major, no major in zero series; declare numbered line first, one italic `CHANGELOG.md` line; `-dev` only → § Release.
- Ship dev first as prerelease, triage by `helm.log`, beta at zero known problems without prerelease flag; push before release; attach zip and image, digest lines of `make-zip.sh`, `make-dmg.sh` in notes, no matching line nothing installs; one `CHANGELOG.md` section and the same `ChangelogData.swift` entries, the two have drifted about which versions exist; never delete or re-tag, undo a bad dev build by the next dev number with the reverted code and its digest lines; say out loud that a prerelease user switching to Beta sees "up to date", so does Dev right after a beta, no fault → § Release, § The updater.
- Edit `dmg-settings.py` and `make-dmg-background.swift` together; judge image by mounting it: Finder settings file well over an untouched one's size, custom-icon flag on the volume, strict signature verification of the app inside; window by container's bounds less title bar, text size not below `dmg-settings.py`'s floor, background against real icons and labels → § The disk image window.
- No ad-hoc build over `/Applications/Helm.app`, grants do not survive, nor does passing strict verification prove they held; certificate named in the personal file `signing-identity.sh` reads, not in script; release with `HELM_SIGN_IDENTITY=- bash Scripts/package-app.sh` → § Release.
